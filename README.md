# СПДО — поиск дубликатов обращений в техподдержку

Веб-система регистрации обращений, которая при создании новой заявки находит
похожие ранее зарегистрированные обращения и предлагает пометить её как
дубликат, связать с похожей или зарегистрировать как новую. Решение всегда
принимает человек.

Ранжирование — взвешенная сумма семантического (sentence-transformers,
pgvector), лексического (TF-IDF/BM25), категориального и компонентного сходства.

## Запуск

```bash
cp .env.example .env
make install
make up          # PostgreSQL + pgvector и приложение, http://localhost:8000
                 # миграции применяются при старте контейнера;
                 # локально: make migrate
```

За обратным прокси (nginx, Traefik) uvicorn должен доверять заголовкам
прокси, иначе все запросы придут с его адреса, а ограничение неудачных
входов по IP-адресу заблокирует вход всем сразу. Укажите адрес прокси в
переменной `FORWARDED_ALLOW_IPS` контейнера (uvicorn читает её сам) или
отключите ограничение по адресу: `SPDO_LOGIN_MAX_FAILURES_IP=0`. Учёт
попыток входа, поисковый индекс и параметры поиска, заданные
администратором, хранятся в памяти процесса, поэтому запускается один
процесс uvicorn.

После обновления до версии со сбросом сессий при смене пароля (миграция
0005) все пользователи один раз входят заново.

## Поиск похожих обращений

Режим (`SPDO_SEARCH_MODE`): `hybrid` (по умолчанию) — взвешенная сумма
семантического (модель `cointegrated/rubert-tiny2`, pgvector), лексического,
категориального и компонентного сходства; `lexical` — базовый режим для
сравнения, только TF-IDF по символьным n-граммам. Модель скачивается с
Hugging Face при первом запуске (около 120 МБ) и дальше работает локально.
Индекс обновляется при регистрации обращения; для уже имеющихся обращений:

```bash
uv run spdo reindex --admin <администратор>
```

Качество подбора на эталонном наборе (recall@3 и др., ТЗ п. 8.2) и подбор
весов и порогов базового режима на настроечной части:

```bash
uv run spdo eval data/synthetic --mode hybrid --json reports/quality/<имя>.json
uv run spdo tune data/synthetic --mode hybrid
```

- UML-модель: `docs/uml/`.
