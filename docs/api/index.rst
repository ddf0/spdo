СПДО — документация на исходный код
===================================

Система интеллектуального поиска дубликатов обращений в техническую поддержку.

При регистрации обращения система подбирает ранее зарегистрированные похожие
обращения и ранжирует их по коэффициенту сходства

.. math::

   S = w_1 S_{sem} + w_2 S_{lex} + w_3 S_{cat} + w_4 S_{comp}.

Решение о связывании обращений принимает пользователь или оператор.
