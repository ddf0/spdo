Пользователи и роли
===================

Подсистема :mod:`spdo.users` отвечает за учётные записи, аутентификацию и
разграничение прав (функция Ф15 ТЗ).

* :mod:`spdo.users.models` — модель пользователя и перечисление ролей;
* :mod:`spdo.users.security` — хеширование паролей bcrypt с солью;
* :mod:`spdo.users.service` — создание, аутентификация, изменение учётных записей;
* :mod:`spdo.users.deps` — зависимости FastAPI: текущий пользователь, роли, CSRF;
* :mod:`spdo.users.routes` — вход, выход и API администрирования.

Роли: пользователь видит только свои обращения; оператор обрабатывает
обращения; администратор ведёт справочники и учётные записи. Права
проверяются на сервере в каждой защищённой операции.
