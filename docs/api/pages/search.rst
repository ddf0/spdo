Поиск похожих обращений
=======================

Подсистема :mod:`spdo.search` скрыта за интерфейсом
:class:`~spdo.search.base.SimilaritySearcher` и не зависит от бизнес-модулей.

* :mod:`spdo.search.base` — интерфейс, структуры запроса и кандидата, двухпороговая
  классификация «дубликат» / «связанное»;
* :mod:`spdo.search.lexical` — базовый режим: лексическое сходство;
* :mod:`spdo.search.hybrid` — основной режим: взвешенная сумма четырёх составляющих;
* :mod:`spdo.search.embeddings` — векторные представления текстов локальной моделью;
* :mod:`spdo.search.factory` — создание поисковика по конфигурации;
* :mod:`spdo.search.models` — поисковый индекс с векторными представлениями.

Качество обоих режимов измеряется командой ``spdo eval`` на проверочной части
эталонного набора (:mod:`spdo.analytics.evaluation`).

Пороги P1, P2, число результатов N и веса w1–w4 задаются только
конфигурацией (:class:`spdo.config.Settings`).
