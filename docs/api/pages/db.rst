Хранение данных
===============

Подсистема :mod:`spdo.db` — доступ к PostgreSQL 16 с расширением pgvector.

* :mod:`spdo.db.base` — декларативная база моделей и соглашение об именах ограничений;
* :mod:`spdo.db.session` — движок SQLAlchemy и фабрика сессий;
* :mod:`spdo.db.models` — реестр моделей всех подсистем для Alembic.

Схема БД создаётся миграциями Alembic (``make migrate``); при запуске
контейнера миграции применяются автоматически.
